# IA al Día

Blog de noticias de Inteligencia Artificial explicadas de forma **simple y cercana** para público no técnico.

Actualizado diariamente y desplegado automáticamente en Vercel.

## Cómo funciona

- Los posts se escriben en Markdown dentro de `src/content/blog/`
- Astro genera el sitio estático
- Cada push a `main` se despliega automáticamente en Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

## Estructura

- `src/content/blog/` → posts en Markdown
- `src/pages/` → páginas del sitio
- `src/layouts/` → layout principal

## Publicación diaria

El plan es generar automáticamente un post cada día con las noticias más relevantes de IA, en tono sencillo.
